# Yan DSGN — Portfólio 3D

Portfólio de Silas Yan, designer gráfico: um quarto em 3D (three.js) onde cada objeto abre uma seção.

- Site estático: `index.html` + `app.js` + `vendor/` (three.js embutido) + `img/`.
- Para editar textos, projetos e contatos: bloco **CONTEÚDO EDITÁVEL** no começo do `<script>` em `index.html`.
- Deploy: Vercel, sem build (Framework Preset: Other).
